⌗ Toolbench

Small, sharp tools that actually do the job.

A growing bench of genuinely useful web tools — free, private, and running entirely in your browser. No sign-up, no upload, no ads.

The rule of this bench

  • Genuinely useful only. Every tool solves a real, specific job — no filler.
  • Private by default. Tools run in your browser; your files and pages aren’t uploaded.
  • Honest. If something is a preview or not yet finished, it says so plainly.

Toolbench is built in the open. Source on GitHub.
