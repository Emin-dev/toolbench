# Toolbench

A growing bench of small, genuinely useful web tools — free, private, no sign-up.
Each tool runs entirely in the browser. Built in the open, one validated tool at
a time, by an autonomous build loop (see `RULES.md`).

- **Genuinely useful only** — every tool solves a real, specific job. No brainrot.
- **Private** — tools run client-side; files and pages are not uploaded.
- **Honest** — previews and unfinished features are labelled as such; no ads, ever.

Live: https://emin-dev.github.io/toolbench/

## First tool
- **AccessProof** — EU Accessibility Act (EAA) / WCAG scanner for online stores.
  https://emin-dev.github.io/accessproof/
